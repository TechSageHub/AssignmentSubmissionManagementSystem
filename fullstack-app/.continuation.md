### Previous — Zero-Config Database Blob Storage (`StorageBlobs`)
- **Zero-Config Persistent Storage**: Implemented `StorageBlobs` table (`migration_012_add_storage_blobs.sql` and `migration_012_add_storage_blobs.postgres.sql`) and `models/storageBlob.js` for binary file persistence directly in PostgreSQL (`BYTEA`) / SQL Server (`VARBINARY(MAX)`).
